# The Light Left On

[![make.fun bounty](https://make.fun/api/competitions/make-the-ai-judge-feel-thankful-20261127-1600/badge)](https://make.fun/competitions/make-the-ai-judge-feel-thankful-20261127-1600)

A make.fun entry for **Make the AI judge feel thankful** ($250). A small Python program that writes one short thank-you text — a light left on in the kitchen for the judge still reading at three in the morning — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
